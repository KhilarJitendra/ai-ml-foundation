## What to learn

### 1. Machine Learning Specialization — Nov 2026–Jan 2027
- Supervised learning, linear/logistic regression and classification
- Decision trees, clustering and recommendation systems
- Model evaluation and practical Python assignments
- **Deliverable:** Complete all graded assignments and earn the specialization certificate.

### 2. Mathematics for Machine Learning — Feb–Apr 2027
- Linear algebra: vectors, matrices and transformations
- Calculus: derivatives, gradients and optimization
- Probability and statistics
- **Deliverable:** Be able to explain the math behind gradient descent and model evaluation.

### 3. Deep Learning Specialization — May–Jul 2027
- Neural networks and backpropagation
- Optimization and regularization
- Convolutional and sequence models
- **Deliverable:** Train and evaluate neural-network models.

### 4. PyTorch tutorials — Jul–Aug 2027
- Tensors and autograd
- Data loaders, training loops and evaluation
- Saving and loading models
- **Deliverable:** Train a small neural network in PyTorch.

### 5. Portfolio project — Aug 2027
**Project:** AI-Based Telecom Network Anomaly Detection System.

1. Find a suitable public telecom/network dataset and document its limitations.
2. Clean and explore data with Python.
3. Establish a simple baseline and train an anomaly-detection model.
4. Evaluate results and false positives on held-out data.
5. Serve predictions through a FastAPI endpoint.
6. Optionally build a React dashboard.
7. Publish a GitHub repository with a README, metrics, limitations and reproducible instructions.
